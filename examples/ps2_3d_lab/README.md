# PS2 3D Wireframe Lab

D-pad: orbit. L1/R1: zoom. X: colour. START: reset.

A perspective-projected cube for initial hardware testing. Uses CPU transforms
and GS line primitives. No audio, texture loading, depth testing, mesh importing
or Godot 3D export. Build with ncc, then launch game.elf from FMCB/wLaunchELF.
