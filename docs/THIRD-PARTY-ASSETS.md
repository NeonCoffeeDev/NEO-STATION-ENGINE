# Third-party editor assets

## GameUI Icon Pack

The compact NC Studio toolbar uses selected raster icons from the user-supplied
GameUI Icon Pack. Copyright (c) 2026 GameUI Icon Pack. The supplied commercial
license permits use and modification in games, apps, and software, but forbids
redistributing the pack as a standalone icon pack. The complete supplied
license and readme are retained beside the used editor icons under
`assets/editor/icons/`.

## FREEPSXUI

The project hub uses selected 240p interface panels from FREEPSXUI by
[rohhsa.itch.io](https://rohhsa.itch.io/). The supplied creator readme is
retained under `assets/editor/hub/`. Only the two panels used by the editor are
included in this repository.
