GameUI Icon Pack — 105 SVG Icons
=================================

A clean, consistent set of stroke-style icons for indie game developers
and UI designers. Every icon follows the same design language:
24×24 grid, 2px round stroke, minimal fills for color hints.

CONTENTS
--------
105 icons across 11 categories:

  - HUD / Stats       (heart, shield, mana, stamina, xp, poison, ...)
  - Weapons           (staff, shield_broken)
  - Armor & Equipment (armor, helmet, boots, cloak, ring, amulet)
  - Currency & Loot   (coin, gem, diamond, ruby, chest, key, ...)
  - Items             (potions, book, scroll, torch, lantern, ...)
  - Navigation        (map, compass, pin, waypoint)
  - Skills & Magic    (fire, ice, lightning, wind, holy, curse, ...)
  - Environment       (tree, mountain, cave, castle, dungeon, portal)
  - Quest & Progress  (trophy, crown, skull, dice, hourglass, ...)
  - Social            (player, chat, trade, guild)
  - UI & System       (settings, save, lock, arrows, sound, ...)

FILE FORMAT
-----------
All icons are standard SVG files (Scalable Vector Graphics).
They can be used at any size without quality loss.

Compatible with:
  - Unity, Godot, GameMaker, RPG Maker
  - Figma, Adobe XD, Illustrator
  - Any HTML/CSS project (inline SVG or <img> tag)
  - React, Vue, and other frontend frameworks

USAGE TIPS
----------
Import directly into your game engine or design tool.
To change colors, edit the stroke and fill attributes in the SVG file
or use CSS: svg { stroke: #ffffff; }

PREVIEW
-------
Open _preview.html in any browser to see all icons at a glance.
